# 小林科技 · 个人接单站

独立开发者「小林科技」的个人主页，用来介绍自动化脚本、前后端与数据库、后台管理系统、App 搭建四类服务，并引导访客扫码添加微信。

**线上地址**：https://lwl555.github.io/xiaolin-tech/

## 特点

- 纯静态：HTML + CSS + 原生 JS，零依赖、零构建，可直接托管在 GitHub Pages
- 视觉方向「墨色朱红」：宣纸底 + 墨色字 + 单一朱红强调色，标题用 Noto Serif SC，无渐变、无毛玻璃
- 明暗双主题，主题切换使用 View Transition 交叉淡入，记忆选择
- 需求编译器：选平台 / 目标 / 规模，实时生成方案草稿（不含报价），可一键复制
- 模拟终端：可输入 `help`、`demo 签到`、`demo 报表`、`price`、`contact`，带命令历史
- 滚动驱动标题横线（CSS `animation-timeline: view()`，零 JS），移动端自动降级
- 完整响应式（1440 / 1024 / 768 / 390），支持 `prefers-reduced-motion`
- 无障碍：跳过链接、键盘可达、焦点圈、弹窗焦点管理，正文/小字对比度均 ≥ 5:1
